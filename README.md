# Sistema de Cadastro de Alunos

Projeto da disciplina de Python (Parte 1): um sistema de cadastro de alunos que roda no terminal.

## Funcionalidades

1. Adicionar aluno (nome, idade e nota de 0 a 10)
2. Listar todos os alunos
3. Buscar aluno pelo nome
4. Remover aluno
5. Mostrar média geral das notas
6. Sair

## Conceitos utilizados

- Listas e dicionários (cada aluno é um dicionário dentro de uma lista)
- Funções (cada opção do menu é uma função)
- Loop principal com `while True`
- Condicionais (`if`, `elif`, `else`)
- Validação de entradas (idade e nota)

## Como executar

É preciso ter o Python 3 instalado. No terminal, dentro da pasta do projeto:

```
python sistema_alunos.py
```
